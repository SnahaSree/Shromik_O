
# SHROMIK

### Trusted Employment. Dignified Work.

Shromik is a digital workforce platform designed to connect construction workers and contractors across Bangladesh.

## Vision

To create a transparent, accessible and reliable construction workforce ecosystem.

## Core Features

- Worker registration and profiles
- Contractor registration and profiles
- Construction job discovery
- Job posting and applications
- Worker ratings and reviews
- Experience and feedback management
- Role-based dashboards
- AI-powered assistant
- Admin management
- Bilingual interface (English and Bangla)

## Technology Stack

- React + TypeScript
- Tailwind CSS
- Framer Motion
- Node.js + Express
- MongoDB Atlas
- JWT Authentication
- Zod Validation

## Project Structure

- frontend: React application
- backend: Express REST API
- docs: Technical documentation
